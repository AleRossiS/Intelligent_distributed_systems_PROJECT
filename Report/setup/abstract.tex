A "treasure hunt" can be a fun and engaging opportunity to test the capabilities of a swarm of robots in a simulated environment. The multiagent system proposed in this project is designed to search for a target in a 2D environment using a combination of swarm intelligence, Voronoi cells, Lévy flight, Angle of Arrival (A0A), and sensor fusion techniques. The main objective of the project is to evaluate the performance of the proposed multiagent system in terms of search efficiency, convergence time, and robustness to noise and uncertainties in the environment. The simulation will be implemented in Python, and the results will be analyzed to draw conclusions about the effectiveness of the proposed approach in solving the treasure hunt problem.
